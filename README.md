# 🎧 Spotify Stats

A simple application that lets you explore your Spotify listening data — top tracks, favorite artists, and more.

## 🚀 Features

* 🔥 View your **top tracks**
* 🎤 Discover your **top artists**
* 📊 Analyze your listening habits
* 🔐 Secure authentication via Spotify API
* ⚡ Fast and lightweight

## 🛠 Tech Stack

* Python
* Spotify Web API

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Zeonbtw/Spotify_Stats.git
cd Spotify_Stats
```

Install dependencies:

```bash
npm install
```

## 🔑 Environment Variables

Create a `.env` file in the root directory and add:

```env
CLIENT_ID=your_spotify_client_id
CLIENT_SECRET=your_spotify_client_secret
REDIRECT_URI=http://localhost:3000/callback
FRONTEND_URI=http://localhost:5173
```

## ▶️ Run the Project

```bash
npm start
```

## 🔗 Spotify API Setup

1. Go to Spotify Developer Dashboard
2. Create an app
3. Add Redirect URI (`http://localhost:3000/callback`)
4. Copy CLIENT_ID and CLIENT_SECRET
